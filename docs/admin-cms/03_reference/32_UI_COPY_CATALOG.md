# Каталог UI-текстов

## 1. Термины

| Code/domain | UI |
|---|---|
| World | Мир |
| Course | Курс |
| Venue | Площадка / организация |
| VenueCampus | Корпус |
| Shift | Смена |
| OfferFormat | Формат участия |
| Draft | Черновик |
| Revision | Версия изменений / ревизия в technical details |
| Release | Релиз |
| Snapshot | Снимок только technical |
| Publish | Опубликовать |
| Rollback | Откатить релиз |
| Archive | Архивировать |

## 2. Save states

- Нет изменений
- Есть несохранённые изменения
- Сохраняем…
- Сохранено в {time}
- Не удалось сохранить
- Серверная версия изменилась
- Изменения сохранены локально

## 3. Publication states

- Не опубликовано
- Готово к публикации
- Есть ошибки
- В очереди
- Проверяем данные
- Собираем релиз
- Загружаем файлы
- Активируем релиз
- Проверяем сайт
- Опубликовано и проверено
- Публикация не завершена
- Откат выполнен и проверен

## 4. Primary actions

- Создать мир
- Создать курс
- Добавить площадку
- Добавить корпус
- Создать смену
- Добавить формат
- Сохранить черновик
- Открыть предпросмотр
- Собрать предпросмотр
- Подготовить релиз
- Опубликовать релиз
- Откатить релиз
- Архивировать

## 5. Empty states

### Courses

> Курсов пока нет. Создайте первый курс или импортируйте существующие данные.

### Filtered

> По выбранным фильтрам ничего не найдено.

Actions:

- Сбросить фильтры
- Изменить условия поиска

### Drafts

> Неопубликованных изменений нет.

### Attention

> Сейчас нет задач, требующих внимания.

## 6. Errors

### Generic fetch

> Не удалось загрузить данные. Повторите попытку.

### Save

> Сервер не ответил. Изменения остались в форме.

### Validation summary

> Проверьте {count} поля перед сохранением.

### Permission

> У вас нет права изменять эту запись.

### Session

> Сессия завершилась. Войдите снова; изменения формы сохранены локально.

### Conflict

> Пока вы редактировали запись, другой пользователь сохранил новую версию.

### Publication verification

> Релиз активирован, но проверка сайта не завершилась. Не считайте публикацию подтверждённой.

## 7. Confirmation dialogs

### Archive

Title:

> Архивировать курс «{name}»?

Body:

> Курс исчезнет из обычных списков после публикации, но история и прошлые релизы сохранятся.

Actions:

- Архивировать курс
- Отмена

### Publish

Title:

> Опубликовать релиз с {count} изменениями?

Body:

> Будут обновлены {pages} страниц. После публикации система проверит сайт.

Actions:

- Опубликовать релиз
- Вернуться к проверке

### Rollback

Title:

> Вернуть релиз {targetRelease}?

Body:

> Публичный сайт вернётся к предыдущему набору данных. Черновики и новые версии не удалятся.

Actions:

- Откатить релиз
- Отмена

## 8. Disabled reasons

- Исправьте {count} ошибки
- Дождитесь обработки медиа
- Сначала сохраните черновик
- У вас нет права публиковать
- Нет соединения с сервером
- Серверная версия изменилась; сравните изменения
- Выберите хотя бы одну смену

## 9. Tone rules

- Не использовать `Упс`, `Ой`, шутки и emoji в error/security/publish flows.
- Не обвинять: `Вы ввели неверно` → `Укажите...`.
- Называть объект.
- Использовать глагол результата.
- Не использовать `синк`, `деплой`, `снапшот` в basic UI.
- Не обещать success до verification.

## 10. Typed contract

```ts
export type ApiClientErrorCode =
  | "AUTHENTICATION_REQUIRED"
  | "PERMISSION_DENIED"
  | "CONFLICT"
  | "VALIDATION_FAILED"
  | "SERVER_ERROR"
  | "HTTP_ERROR";

export class ApiClientError extends Error {
  readonly name = "ApiClientError";
  constructor(readonly code: ApiClientErrorCode, readonly status: number) {
    super("API request failed");
  }
}
```

Safe fields only: `name`, `message`, `code`, `status`.
`cause` absent. No raw payload retention.

## 11. Status mapping table

| HTTP status | `ApiClientError.code` |
|---:|---|
| 401 | `AUTHENTICATION_REQUIRED` |
| 403 | `PERMISSION_DENIED` |
| 409 | `CONFLICT` |
| 422 | `VALIDATION_FAILED` |
| 500–599 | `SERVER_ERROR` |
| any other non-2xx | `HTTP_ERROR` |

Mapping uses HTTP status only.

## 12. Raw-payload rule

For non-2xx: do not call `res.json()` / `text()` / `blob()` / `arrayBuffer()`.
Thrown error must not contain marker `SYNTHETIC_PRIVATE_BACKEND_DETAIL_M1_03`
in `String(error)` or `JSON.stringify(error)`.

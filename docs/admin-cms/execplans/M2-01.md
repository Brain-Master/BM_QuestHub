## 8. State vocabulary

```ts
APP_SHELL_STATES = Object.freeze(["loading", "error", "authorized"] as const)
```

Discriminated `AppShellState` carries only `kind` and bounded `message` strings
for loading/error. Never retains raw `Error`, stack, cause, payload, response,
or snapshot issues.

## 9. Semantic shell

`AppShell` is pure: only `import type { ReactElement, ReactNode } from "react"`.
No hooks, API, auth, storage, environment, router, timers, or logging.

Exact regions:

- skip link → `#admin-main-content` / «Перейти к основному содержимому»;
- `.app-shell` + `data-shell-state={state.kind}`;
- header / utility (`aria-label="Подключение и состояние"`) / navigation wrapper
  + `nav` (`aria-label="Разделы текущего инструмента"`) / main
  (`id="admin-main-content"`, `tabIndex={-1}`).

Nav label intentionally avoids a global-navigation claim.

## 10. Accessibility / responsive

CSS adds skip-link (hidden until focus), shell grid, `main { min-width: 0 }`,

`prefers-reduced-motion`, `overflow-x: hidden` on body. Legacy `.panel` / `.tabs`
/ `.editor` / button styles preserved and not hidden.

## 11. App integration

- One `<AppShell>`; initial shell state `{ kind: "authorized" }` so no-token users
  still reach token controls (not an RBAC claim).
- Refresh: missing API URL → error with existing bounded constant; before
  `loadSnapshots` → loading «Загружаем данные»; success → authorized; non-auth
  error → error via `formatUiError(...).text`; 401 → retain authorized.
- Exactly one `handleRequestError` (empty deps); auth branch ends with `return;`;
  non-auth uses `setStatus(formatUiError(error).text)`.
- Never `String(error)` / `.message` / `.stack` / `.cause` / `JSON.stringify(error)`
  for shell error text.
- Utility = API/token/refresh panel; status = `data-auth-state` status node;
  navigation = five legacy tabs; children = editor/publish.

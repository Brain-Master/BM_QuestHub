## 2. Objective

Заменить показ произвольных `error.message` / `String(error)` в admin UI одним
pure, детерминированным formatter: known errors → bounded Russian copy; unknown →
один generic fallback; optional sanitized correlation ID; без raw
message/stack/cause/payload/issues.

## 3. Business / security value

Editor видит безопасный русский статус без утечки backend payload, stack,
parser fragments или snapshot diagnostics. Correlation ID позволяет поддержке
связывать инцидент без раскрытия секретов.

## 4. Canonical contract

| Input | Exact Russian copy |
|---|---|
| `ApiClientError` AUTHENTICATION_REQUIRED | Требуется повторная авторизация |
| `ApiClientError` PERMISSION_DENIED | Недостаточно прав для выполнения операции |
| `ApiClientError` CONFLICT | Данные изменились. Обновите снимки и повторите действие |
| `ApiClientError` VALIDATION_FAILED | Сервер отклонил данные. Проверьте содержимое |
| `ApiClientError` SERVER_ERROR | Сервис временно недоступен. Повторите попытку позже |
| `ApiClientError` HTTP_ERROR | Не удалось выполнить запрос |
| `DOMException` TimeoutError | Сервис не ответил вовремя. Повторите попытку |
| `DOMException` AbortError | Запрос отменён |
| `SnapshotBundleValidationError` | Получены несовместимые данные. Обновление остановлено |
| `SyntaxError` | Некорректный JSON. Проверьте синтаксис |
| every other value | Не удалось выполнить операцию |

Public API:

```ts
export type UiErrorPresentation = Readonly<{
  text: string;
  correlationId: string | null;
}>;
export function formatUiError(error: unknown): UiErrorPresentation;
```

Correlation: optional sanitized inbound ID from `x-request-id` then
`x-correlation-id`; rendered as `<base> Код обращения: <id>` when safe.

## 11. Correlation-ID policy

- Private sanitizer in `api.ts`: `^[A-Za-z0-9][A-Za-z0-9._:-]{0,63}$`; no trim;
  reject empty/whitespace/control/>64/non-string; reject secret-like substrings
  (`token`, `secret`, `password`, `authorization`, `bearer`, `api-key`,
  `api_key`, `sk-`, `ghp_`, `gho_`, `ghu_`, `ghs_`, `ghr_`).
- Headers priority: `x-request-id`, then `x-correlation-id`.
- Rejected value never stored/logged/displayed.
- Formatter defence-in-depth re-sanitizes `ApiClientError.correlationId`.

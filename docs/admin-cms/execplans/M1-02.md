## 9. Auditor B — race/leak/false-pass risks

| Risk | Mitigation |
|---|---|
| Shared controller | New `AbortController` per request |
| First cause overwrite | `abort()` no-ops if already aborted; cause set once |
| Pre-aborted caller | Immediate `manual` before timer |
| Listener/timer leak | `cleanup` in `finally` always |
| Network misclassified as abort | Remap only when `abort.signal.aborted` + known cause |
| HTTP error as timeout | HTTP path outside catch remap |
| `AbortSignal.any` / `.timeout` | Forbidden; manual composition |
| Fake timer without rejection assert | Attach `expect().rejects` before advance |
| Mock ignores signal | Pending mock rejects on abort event |
| Weakened mutation tests | Keep exact URL/body asserts; only add signal checks |

## 11. Cancellation state machine

```text
PENDING
├─ response/network settles first
│  └─ SETTLED; timer/listener cleaned
├─ caller signal aborts first
│  └─ MANUAL_ABORT; internal signal aborts; AbortError
└─ 15,000 ms timer fires first
   └─ TIMEOUT; internal signal aborts; TimeoutError
```

First cause is immutable. Pre-aborted caller signal starts as `MANUAL_ABORT`.

## 14. Implementation

Added:

- internal `REQUEST_TIMEOUT_MS = 15_000`
- exported `ApiRequestOptions = { signal?: AbortSignal }`
- internal `createRequestAbort(signal?)` with first-cause `timeout|manual`
- optional `options` on `loadSnapshots` / `saveSnapshot` / `publishContent`
- `signal` in every `fetch` init
- catch remap → `DOMException("Request timed out","TimeoutError")` /
  `DOMException("Request cancelled","AbortError")`
- `finally` → clear timeout + remove caller listener

Preserved exactly: `API_URL`, GET/HEAD query path, no GET/HEAD body, mutation URL,
mutation JSON envelopes, headers, token key, JSON parse, HTTP error messages,
return types, snapshot type declarations.

Prohibited patterns absent: `AbortSignal.timeout`, `AbortSignal.any`, Promise.race
pseudo-timeout, shared controller, retry.

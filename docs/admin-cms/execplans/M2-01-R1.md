## Defect and false-pass

### Confirmed MAJOR defect

Original CSS contained:

```css
body {
  margin: 0;
  overflow-x: hidden;
}

.skip-link {
  position: absolute;
  left: -9999px;
}
```

Global `overflow-x: hidden` conceals overflow instead of proving reflow. It can
clip long API URLs / technical identifiers, controls and focus outlines at
200–400% zoom, and future shell content that exceeds the viewport. This
conflicts with the UX requirement that zoom/reflow must not lose actions or
content.

### False-pass mechanism

Original S12 required:

```ts
expect(css).toMatch(/overflow-x:\s*hidden/);
```

S12 therefore passed because the clipping rule existed. It did not prove usable
reflow. Pre-correction baseline recorded shell **12 / 12** and full **11 / 144**
as a green false-pass on this point.

M2-01 ExecPlan previously recorded `overflow-x: hidden` as an accepted
responsive feature; that claim is withdrawn by this correction.

## Accessibility / reflow requirement

Zoom and narrow viewports must keep actions and content reachable. Reflow must
wrap or shrink content; it must not mask overflow with global clipping.
Skip-link focus must reveal the full link without creating horizontal overflow
or using off-screen horizontal displacement.

## Corrected CSS

### 7.1 Remove global clipping

No `overflow-x: hidden` or `overflow-x: clip` on `html`, `body`, `#root`,
`.app-shell`, `.app-shell__body`, `.app-shell__utility`, `.app-shell__main`.
Not replaced with equivalent global clipping.

### 7.2 Safe skip link

```css
.skip-link {
  position: absolute;
  left: 0.75rem;
  top: 0.75rem;
  z-index: 100;
  transform: translateY(calc(-100% - 1rem));
  padding: 0.75rem 1rem;
}

.skip-link:focus,
.skip-link:focus-visible {
  transform: translateY(0);
}
```

Forbidden patterns removed: `left: -9999px`, horizontal off-screen displacement,
`display: none`, `visibility: hidden`, focus still clipped.

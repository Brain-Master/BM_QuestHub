## 1. Objective

Спрятать текущее чтение/запись shared content-admin token из
`sessionStorage` за одним temporary deprecated `LegacyTokenAdapter`, не
меняя legacy auth mechanism и не расширяя его использование.

## 2. Security value

Единая точка доступа к browser token storage упрощает будущий M1-08
(401 clear) и M3 (server session) без размазанных `sessionStorage` reads
по App/API. Token values не логируются.

## 3. Non-goals

- token clear on 401 (M1-08);
- login/logout, cookies, server sessions, BFF, RBAC;
- token rotation/validation/expiry/cross-tab/encryption;
- localStorage migration;
- UI redesign / removal of token input;
- replacement of shared-token auth;
- M1-08 / M1-09 / M2;
- merge of this PR.

## 11. Read / write semantics

- `read()`: `sessionStorage.getItem(privateKey) ?? ""` — no trim/validate/log/catch.
- `write(value)`: `sessionStorage.setItem(privateKey, value.trim())` — no clear/removeItem.
- Storage errors propagate.
- Module import does not touch storage.

## 1. Objective

Добавить dependency-free runtime validation текущего flat ответа
`GET /snapshots` и интегрировать её в `loadSnapshots()` так, чтобы
malformed successful JSON отклонялся typed bounded diagnostic без raw
payload.

## 2. User value

Admin client больше не принимает успешный HTTP-ответ с неверной формой
snapshot envelope как валидный domain object; ошибка формы отделена от
HTTP/timeout/network failures.

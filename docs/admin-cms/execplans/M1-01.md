## 10. Exact source change (implemented)

Added `requestUrl(method, path)`: GET/HEAD → `new URL(API_URL)` + `searchParams.set("path", path)`; else `API_URL`.

`request`: `RequestInit` with method/headers; `body` only when method is not GET/HEAD using prior payload construction; `fetch(requestUrl(...), init)`.

Unchanged: public exports/signatures, `SnapshotsBundle`, env var, sessionStorage key, headers values, JSON parse, error block, mutation payload/order, mutation URL.

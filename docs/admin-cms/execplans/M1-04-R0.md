## 14. Null / missing / additive policy

1. All six known properties required as own properties.
2. `ok` must be literal `true`.
3. `catalog`/`map`/`site`: plain object only; null/array/primitive → invalid.
4. `manifest`/`offers`: plain object **or** `null`; missing → invalid.
5. Unknown top-level keys: allow and preserve; do not strip; do not reject.
6. Do not treat null as missing.

## 15. Validation depth

**SHALLOW_ENVELOPE_ONLY.** No deep key checks, no version literals, no entity
arrays. Those remain M1-09 (+ fixtures M1-05).

## 16. Bounded diagnostic contract

```text
throw SnapshotBundleValidationError {
  name: "SnapshotBundleValidationError"
  code: "SNAPSHOT_BUNDLE_INVALID"
  message: "Snapshot bundle failed validation"
  issues: Issue[]  // length 1..5
}

Issue {
  path: "$" | "$.ok" | "$.catalog" | "$.map" | "$.site" | "$.manifest" | "$.offers"
  code: "REQUIRED" | "INVALID_TYPE" | "INVALID_VALUE"
  expected: "literal true" | "object" | "object|null"
}
```

No `actual` / raw value fields. Stable path order as ENV-009. Cap at 5 issues.

## 17. Recommended corrected M1-04 type

Preferred exported semantic type (known fields precise):

```ts
export type SnapshotsBundle = {
  ok: true;
  catalog: Record<string, unknown>;
  map: Record<string, unknown>;
  site: Record<string, unknown>;
  manifest: Record<string, unknown> | null;
  offers: Record<string, unknown> | null;
};
```

Additive fields: **runtime** ALLOW_AND_PRESERVE on the returned original object.
Optional TS expression for documentation of openness:

```ts
export type SnapshotsBundle = {
  ok: true;
  catalog: Record<string, unknown>;
  map: Record<string, unknown>;
  site: Record<string, unknown>;
  manifest: Record<string, unknown> | null;
  offers: Record<string, unknown> | null;
  [key: string]: unknown;
};
```

Index signature is acceptable **only if** named properties remain as above
(they are assignable to `unknown`). Prefer documenting runtime preserve even if
the public type omits the index signature to avoid bracket-access widening.
Do **not** widen `ok` to `boolean` or roots to unconstrained `unknown` in the
corrected type (current `api.ts` is looser than producer).

## 18. Recommended parser semantics

1. Input: successful HTTP JSON value (post M1-03 non-2xx mapping).
2. Validate shallow envelope per §§13–16.
3. On success: **return the same object identity** (no clone).
4. On failure: throw `SnapshotBundleValidationError` with ≤5 issues, no raw values.
5. Wire into `loadSnapshots` only after `res.ok` success parse.
6. HTTP/timeout/abort/network remain outside parser (M1-02/M1-03 unchanged).

## Confirmed original defect

Original private `readNow` behaved as:

1. try custom `now()` when provided;
2. on throw / non-finite, fall through;
3. return unguarded `performance.now()`.

### Defect A — custom failure uses another clock

Thrown or non-finite custom clocks fell back to `performance.now()` rather than
`0`, making duration environment-dependent and defeating deterministic injection.

### Defect B — default clock is unguarded

`performance.now()` sat outside `try/catch`. Because `readNow` runs before
`execute` and inside `withApiObservation.finally`, a throwing default clock
could prevent fetch start, replace a successful result, replace the original
API/network error, or prevent terminal observation.

Targeted reproduction on head `7c7f5849…`:

- default clock throw before execute → `executeCalled=false`, error
  `default clock boom`;
- custom throw with default also throwing in finally → success replaced by
  `default clock boom`.

## Original false-pass mechanism

Original Q29 used a custom clock that throws while real `performance.now()`
remained functional. It verified operation preservation and observer/factory
isolation, but:

- did not assert `durationMs === 0`;
- never forced default `performance.now()` to throw or return non-finite.

Therefore Q29 proved fallback-to-default, not complete clock isolation.

## Corrected readNow contract

Private `readNow` in `apps/admin/src/api.ts` (not exported; not moved):

```ts
function readNow(options?: ApiObservabilityOptions): number {
  const clock =
    typeof options?.now === "function"
      ? options.now
      : () => performance.now();

  try {
    const value = clock();
    return typeof value === "number" && Number.isFinite(value) ? value : 0;
  } catch {
    return 0;
  }
}
```

Exact semantics:

- custom finite number returned exactly;
- custom throw / NaN / ±Infinity → `0`;
- failed custom clock does not call default clock;
- no custom clock: finite `performance.now()` returned exactly;
- default throw / non-finite → `0`;
- no error/log/raw value retained;
- duration normalization, request IDs, emission, taxonomy, request behavior
  unchanged.

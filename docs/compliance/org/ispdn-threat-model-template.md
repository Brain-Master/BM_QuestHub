**Дата:** «___» __________ 2026 г.

## 1. Описание ИСПДн

- Источник: форма на статическом сайте (HTTPS).
- Обработка: Yandex Cloud Function на территории РФ.
- Хранение: сервер Оператора на территории РФ (журнал заявок).
- Передача заявок: только через Yandex Cloud (РФ).

_Dev до публикации: временно возможны Google Sheets и Telegram в тестовой среде — не продакшен, см. [data-processing-decision.md](../data-processing-decision.md)._

## 2. Категория обрабатываемых ПДн

Общедоступные не являются; типовые ПДн граждан; данные несовершеннолетних — с согласия представителя.

## 3. Основные угрозы (примеры)

| Угроза | Мера |
|--------|------|
| Перехват трафика | TLS на сайте и API |
| Несанкционированный доступ к журналу заявок | Ограничение доступа к серверу, учётные записи сотрудников |
| Утечка токенов облака | Секреты в YCF, не в `NEXT_PUBLIC_*` |
| Несанкционированный доступ к API приёма заявок | CORS, валидация payload, rate limiting |
| Вредоносный ввод в форму | Валидация на клиенте и в `bm-lead-receiver` |

## 4. Уровень защищённости (предварительно)

Для автоматизированной обработки заявок без спецкатегорий ПДн часто применяют **УЗ-2** (уточнить с ИБ-специалистом / юристом по приказу ФСТЭК № 21).

| Параметр | Значение |
|----------|----------|
| Предлагаемый уровень | УЗ-2 |
| Обоснование | Автоматизированная обработка ПДн клиентов через интернет |
| Дата пересмотра | Ежегодно или при смене инфраструктуры |

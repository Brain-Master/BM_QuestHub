# Регламент рассмотрения обращений субъектов ПДн и отзыва согласия

**Оператор:** ИП Ткаченко Артём Алексеевич (BrainMaster)  
**Версия:** 1.0

## 1. Каналы обращений

- Email: `ask@b-master.pro` (юридический / ПДн)
- Телефон: см. политику на сайте
- Почтовый адрес: см. `/legal/operator-details/`

## 2. Типы обращений

- доступ к ПДн;
- уточнение, блокирование, уничтожение;
- отзыв согласия;
- разъяснение порядка обработки.

## 3. Сроки ответа

Ориентир — **до 30 календарных дней** с даты получения обращения (уточнить с юристом под актуальную редакцию 152-ФЗ).

При необходимости запросить документы, подтверждающие полномочия заявителя (для данных несовершеннолетнего).

## 4. Отзыв согласия

1. Зафиксировать дату и канал отзыва в журнале (таблица или CRM).
2. Прекратить обработку, если нет иных законных оснований (договор, обязанность хранения).
3. Уничтожить или обезличить данные в срок, указанный в политике.
4. Направить ответ о принятых мерах на контакт, указанный заявителем.

В таблице заявок фиксировать `policyVersion` и `consentAt` из формы для доказательства согласия.

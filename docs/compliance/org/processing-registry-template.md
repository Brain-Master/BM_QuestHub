## Операция 1 — Заявки с сайта Quest Hub

| Поле | Значение |
|------|----------|
| Цель | Приём и обработка заявок и предзаписи на программы BrainMaster |
| Категории субъектов | Родители/законные представители; несовершеннолетние (участники) |
| Состав ПДн | ФИО родителя, телефон, email (если указан), ФИО и возраст ребёнка, выбор программы/площадки, комментарии |
| Правовое основание | Согласие субъекта (чекбокс в анкете + текст согласия на сайте) |
| Способы обработки | Сбор через веб-форму, автоматизированная запись, хранение, уточнение, использование, удаление |
| Срок хранения | 1 год с момента заявки или до отзыва согласия (см. политику на сайте) |
| ИСПДн | Сайт (Yandex Cloud, РФ), YCF `bm-lead-receiver` (РФ), сервер Оператора (РФ) |
| Обработчики | Yandex Cloud; сервер Оператора (РФ) |
| Локализация | Только территория РФ |
| Меры защиты | HTTPS, секреты в облаке, ограничение доступа к серверу журнала заявок |
| Уведомление РКН | № ___ от «___» __________ 2026 г. |

_Примечание оператора (не для публикации): в dev до cutover lead-receiver может использовать Google Sheets и Telegram — см. [data-processing-decision.md](../data-processing-decision.md)._

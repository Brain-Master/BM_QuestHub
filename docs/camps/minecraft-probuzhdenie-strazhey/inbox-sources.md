## Как это стыкуется с продуктом «Minecraft: Пробуждение стражей»

- **Идея Minecraft-2.md** логически продолжает сюжет [«Тайна древних инженеров»](../minecraft-taina-drevnih-inzhenerov/README.md) (портал, пробуждение мобов, **система защиты**, главный проект на столе). Использовать как черновик идей; **канон по проведению** — Google Doc «диск» лагеря (полная ссылка в [operations-manual.md](operations-manual.md) и [README.md](README.md)).
- **Архипелаг + MainCraft 2 + ТЗ по дням 1–3** описывают **другую рамку** («Искатели», четыре стихии, слайды на смену). Это может быть: отдельная линейка лагеря, оболочка презентаций для той же смены, или черновик под другой SKU — **нужно продуктовое решение**, чтобы не смешивать в одной карточке сайта два разных «Дня 1».

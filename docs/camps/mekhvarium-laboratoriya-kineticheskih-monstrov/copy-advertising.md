## Выжимка (2–4 нейтральные формулировки)

1. **Сеттинг:** лаборатория кинетических «монстров»: протоколы смены, **деревянный каркас с шестернями**, «мышцы» из воздушного пластилина, акрил, **кибер-броня 3D-ручкой**; плюс финал с **TinkerCAD**, симуляцией и выставкой для родителей (см. сценарии на Drive).  
2. **Технологии:** физика и механика (рычаги, передачи), декор и покраска по регламенту, 3D-ручка; **TinkerCAD** / **SimLab** в финале; механическая **шкатулка с секретом** + **робо-монстр** как опорные образы результата (из официального описания).  
3. **Результат:** готовый робо-монстр домой; в программе с TinkerCAD — также цифровой двойник, краш-тесты, паспорт монстра, сертификаты.  
4. **Для родителей:** практика без «сухой теории», протоколы безопасности, адаптация под новичков и «профи»; для летнего полного дня — питание (уточнять в актуальной оферте).

*Программа самостоятельна от «Мастерской гидравлических монстров» — в текстах не подразумевать обязательный другой квест.*

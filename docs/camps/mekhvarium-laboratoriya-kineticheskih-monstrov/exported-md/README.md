# Экспорт методичек (копия из Inbox)

Файлы — **копии** оригиналов из `d:\WORK\00_Inbox\` на момент добавления в репозиторий. Канон при расхождении — актуальные документы на [Google Drive](../google-drive-index.md) (папка сценариев).

### Единый формат в репозитории

Во всех методичках ниже:

- один заголовок первого уровня `#` — название документа;
- блок цитаты с **оригиналом (Inbox)** и ссылкой на **канон** на Drive;
- строка **Документ:** (тип: сценарий, плейбук, тайминг, …);
- при необходимости — **концепция**, **длительность**, **роль**;
- далее `##` / `###` для актов и сцен, списки `-`, курсив для реплик и сценических ремарок.

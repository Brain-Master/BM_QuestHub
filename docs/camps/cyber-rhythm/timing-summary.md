# Сводка по таймингу: КиберРитм

Цель файла — одним экраном показать **два способа нарезки дня** в черновиках и указать, где искать детали.

## Источники

- Поминутные и поурочные планы — [exported-md/scenario-day-01.md](exported-md/scenario-day-01.md) … [scenario-day-05.md](exported-md/scenario-day-05.md).
- Сжатый обзор программы без времени — [raw/Краткий план интенсива «КиберРитм».md](raw/Краткий%20план%20интенсива%20«КиберРитм».md).
- Актуальная смена — методичка на [Google Drive](google-drive-index.md).

## Паттерн A — слотовое расписание (дни 1, 3, 4, 5 в черновиках)

Типичная сетка из файлов по дням:

| Интервал | Содержание |
|----------|------------|
| 09:15–09:30 | Сбор, круг настроения |
| 09:30–10:15 | Урок 1 |
| 10:15–10:30 | Перерыв |
| 10:30–11:15 | Урок 2 |
| 11:15–11:30 | Перерыв |
| 11:30–12:15 | Урок 3 |
| 12:15–12:30 | Перерыв |
| 12:30–13:15 | Урок 4 |
| 13:15–14:30 | Закрытие дня, рефлексия, ДЗ |

**Оговорка:** в дне 1 блок «13:15–14:30» в исходнике объединяет рефлексию и домашку — по факту может быть короче на живой смене; сверять с Drive.

## Паттерн B — четыре урока по 45 минут (день 2 в черновике)

| Блок | Длительность | Содержание |
|------|--------------|------------|
| Урок 1 | 45 мин | Обратная связь, мост к струнам |
| Урок 2 | 45 мин | Теория струнных |
| Уроки 3–4 | 90 мин | TinkerCAD + сборка арфы |
| Завершение | ≈45 мин в raw | Круг, ДЗ, затравка |

Перерывы в тексте дня 2 могут быть встроены в 90-минутный блок — явная поминутная сетка в исходнике не дублируется; при необходимости вынести из Drive отдельным листом.

## Несогласованность дат между файлами

В именах файлов и заголовках встречаются **7.03**, **8.03**, **8.04**, **9.03**, **9.04**, **10.03**, **10.04**, **11.03**, **11.04** — это артефакты разных правок сессий. Для публикации и новой смены использовать только **календарь и тайминг из операционки**, не даты из markdown.

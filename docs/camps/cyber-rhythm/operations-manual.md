# Руководство проведения: КиберРитм

## Официальные источники

Методика и материалы по дням ведутся в **Google Drive** (папки по дням, модели на печать, PDF — см. оглавление в индексе):

- **[Индекс Drive →](google-drive-index.md)** — корневая папка и состав верхнего уровня.

## Зеркало в репозитории

- **[exported-md/README.md](exported-md/README.md)** — сценарии **День 1–5** в единой редакции (`scenario-day-01.md` … `scenario-day-05.md`), удобные для навигации и сверки с Drive.
- **[raw/README.md](raw/README.md)** — исходные копии без выравнивания разметки: учебный план, файлы по дням (`КиберРитм__7-03__Первый_день__Свисток.md` и т.д.), описание для площадки, архивные посты.
- **[timing-summary.md](timing-summary.md)** — сводка слотового расписания и особенностей дня 2.

При расхождении **`exported-md`** vs **`raw`** vs **Drive** — **приоритет актуальной версии на Drive** и решение методиста; файлы в git — для офлайна и истории правок.

## Оглавление в git

Краткое **оглавление** полного руководства (разделы по дням, безопасность, расходники, роли) можно добавить сюда после выбора одного канонического документа (единый GDoc или экспорт из Drive). Пока структура программы по дням зафиксирована в:

1. Папках **День №1 … День №5** на Drive ([google-drive-index.md](google-drive-index.md)).  
2. Файлах по дням в [raw/](raw/README.md).

Даты и номера уроков в именах файлов `raw/` отражают конкретную сессию в источнике — для новой смены сверять с актуальной методикой на Drive и с [timing-summary.md](timing-summary.md).

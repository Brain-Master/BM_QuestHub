## Риски

- **Права на медиа:** диск фотографа ([a-simonov.ru](https://a-simonov.ru/disk/inzhenernyy-kvest-x32k78)) — подтвердить договорённости на рекламу, срок ссылки, кредит на сайте. **VK-альбомы:** согласование лиц и детей для баннеров — по внутреннему регламенту BrainMaster.  
- **Юридическое / брендинг:** **Minecraft** — зарегистрированная интеллектуальная собственность Microsoft. Публичные формулировки, визуалы и хэштеги с упором на бренд игры сверить с **юридическим** до массового тиража (сайт, контекст, наружка). В документации репозитория допустимы рабочие формулировки «по мотивам / вселенной Minecraft»; итоговый копирайт для рекламы — после правки.  
- **Данные для записи:** цены, даты смен, адреса и ссылки на запись не тянуть из архивных постов — только из CRM / календаря / актуальной воронки.

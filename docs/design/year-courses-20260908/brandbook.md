# Product surface guide

Не менять существующий бренд-знак. Тёмно-синяя среда сохраняет связь с QuestHub. Зелёный акцент обозначает действия и короткие тематические подписи; основной текст светлый, пояснения серо-голубые. Избегать градиентного текста поверх фотографий, произвольных стоков и вымышленных отзывов.

Заголовки Onest: крупные, плотные, не более одной смысловой идеи. Тело Manrope: line-height 1.75. Фото на карточках 16:10, герой — крупный кадр наставника и ученика; лица не закрывать надписями. Видео только по действию пользователя, с подписью источника и текстовым описанием. Успех ученика не равен гарантии успеха будущего участника.

Schedule cards use text labels as well as colours: source-open green (#acf2c3 on #143b2b), closed neutral (#e1e3ed on #353746), dated caution amber (#f2d59d). The green action accent does not certify seat availability. Preserve the prominent source-date warning; missing values use explanatory text, not zero. Editable master remains year-courses.css with ys-* component classes.

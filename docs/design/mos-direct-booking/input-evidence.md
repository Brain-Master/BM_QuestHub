# Источники и уверенность

Факты: владелец сообщает, что обязательная анкета мешает переходу. Текущий
OfferBookingAction действительно открывал её для всех mos-действий. Успех
MosBookingSuccess автоматически открывал портал через три секунды; ошибка
заменяла заполненную форму экраном перехода. Общая кнопка используется в
расписании, годовых программах и вариантах интенсивов; YearSchedule имеет
отдельные прямые ссылки. Проверено по текущему коду, не по старым скриншотам.

Ограничения: источник URL — существующий bookingMode, который сохраняет
закрытый приём, архив, отсутствие мест и проверку карточки. Уведомление о клике
не содержит контактных полей. Инфраструктура всё равно видит IP соединения.
Публикация и реальные сообщения не входят в локальное выполнение.

Гипотеза: необязательная помощь после прямой ссылки уменьшит отказ от перехода.
Это не измеренный результат; количественное исследование не проводилось.

Источники: запрос владельца21.09.2026; компоненты offer-booking-action,
mos-booking-success, booking-form, year-schedule; lib/offers/schedule-board.ts;
два независимых read-only аудита; локальные браузерные проверки.

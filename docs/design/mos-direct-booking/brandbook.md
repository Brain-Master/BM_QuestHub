# Правила поверхности

Анатомия: существующие программа/возраст/корпус/время/цена → основная ссылка
«Записаться на mos.ru» → пояснение нового окна → «Оставить контакты» → добровольность.
Не помещать основное действие в «Подробнее» или внутрь анкеты.

Состояния: доступна запись — два независимых действия; закрыта/архив/нет мест —
существующая заблокированная кнопка либо разрешённый лист ожидания. Загрузка
и отсутствие групп принадлежат текущему расписанию, здесь не меняются.
Анкета: незаполнена, ошибки полей, отправка с disabled, ошибка сервиса с
сохранёнными полями, подтверждённый успех. Не показывать успех по факту клика.

Сохраняем lime основной кнопки каталога, её тёмный текст и светлую/тёмную темы
мастера. В остальных карточках сохраняем текущий градиент mos.ru. Вторичная
кнопка прозрачная, с подчёркиванием. Диалог — существующий тёмный; маленький
вспомогательный текст не темнее slate400 после проверки контраста.

Контроль: реальные ссылки, видимый focus, Enter/средняя кнопка/Ctrl-click,
44px touch targets, wrapping при320px. Модальное окно не вызывает новое само.
Логотипы/печатные носители/новые иллюстрации к этому срезу не относятся.

# Продукты и курсы BrainMaster

**Идея:** все внебюджетные программы в агрегаторе отображаются как **инженерные квесты** (единый UX-паттерн карточки), при этом в школах годовые линейки при желании можно продолжать позиционировать как **строгие учебные курсы** (см. [BrainMaster-обзор-и-позиционирование.md](BrainMaster-обзор-и-позиционирование.md)).

## Типы продуктов в списке курсов

| Тип | Суть | Типичные поля в карточке |
|-----|------|--------------------------|
| **Каникулярный интенсив** | 5 дней, ядро ~3,5 ч инженерного блока в день (уточняется по площадке); возможен пакет школы (продление дня, питание и т.д.) | Возраст, навыки, смены по датам, площадки, цена/диапазон, запись |
| **Годовой курс** | 1–3 занятия в неделю, модули ~1,5 мес, проект за модуль | Возраст, траектория модулей, стоимость за занятие/месяц, запись |

### Пример годового продукта (для контента сайта)

**ШМИ-1** («Школа молодого IT-инженера»): электроника, пайка, 3D, LEGO-робототехника, Scratch и др. Соцдоказательство: через программу прошли **почти 1000 детей** (использовать в карточке/лендинге после финальной выверки формулировки с юридическим). Актуальная цена и ссылка на регистрацию — только из **операционного источника правды** (не из черновиков).

**Мехвариум:** две программы **независимы** — нет обязательного порядка «сначала одна, потом другая».

По части программ уже есть **видео, фото, руководство проведения**; по новым — заполнять карточку честным минимумом без выдуманных отзывов. У **Minecraft: Пробуждение стражей** в репозитории заведены [экспорт черновиков и сценарии по дням](camps/minecraft-probuzhdenie-strazhey/exported-md/README.md) (копии из Inbox; канон проведения — Google Doc из хаба).

## Площадки (типы баз)

1. **Школа-партнёр** — договор родитель–школа, школа–BrainMaster; запись и оплата через **mos.ru** (текущая модель).
2. **Собственная база BrainMaster** (вне школы) — тот же объект в списке курсов; **оферта и оплата** могут отличаться (зафиксировать при запуске каждой базы).

У каждой площадки в данных: **тип**, **название**, **адрес**, **метро** (запись возможна **с других школ и районов**).

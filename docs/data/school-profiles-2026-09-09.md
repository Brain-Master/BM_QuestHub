## Фотографии и логотипы

`scripts/school-media-sources.json` хранит точные CDN URLs и исходные карточки для
каждого нового скачанного JPEG. `scripts/fetch-school-media.mjs` проверяет hostname,
MIME, JPEG signature, ограничивает файл 5 MB, таймаут 20 s, не перезаписывает файлы;
выводит SHA256. Для 2044 подробный реестр уже находится в
`apps/web/public/sites/school-2044/README.md`.

Файлы с `original` содержат неизменённые байты скачанного варианта CDN (`S`,
`L_height`, `XXXL` либо `orig`), это не утверждение о полном размере исходника камеры.
Изображения визуально проверены основным агентом. Фотографии 875/99к2 и 2103/13к2
подписаны как вход/подход к территории: фасад закрыт оградой/деревьями.
Для 17/27А выбран фасад вместо спортивной площадки; для 1212/21к3 — другой кадр
вместо фотографии с крупной датой 2016. Отброшенные локальные кандидаты сохранены,
но в профилях не используются. Водяные знаки не удалялись, здания не генерировались.
Старый `venues/logos/school-1383.webp` оказался техническим placeholder; новый
логотип взят из owner_photo школы 1383 (карточка корпуса № 2). Старый файл не удалён.

Источники фотографий доступны по ссылке рядом с фото. Публичная доступность не
означает свободную лицензию: разрешение на переиспользование отдельно не подтверждено.
Перед публичным выпуском медиапакета владелец должен подтвердить право использования
или предоставить собственные фотографии. Кандидат не публиковался автоматически.

Не добавлены: неподтверждённое почётное имя школы 1517, непроверенный официальный
домен школы 937 и ошибочный Telegram `mducekd` (это другой канал).

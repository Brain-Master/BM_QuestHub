# Бизнес-цели сайта-агрегатора (Quest Hub)

**Статус:** рабочий документ для продукта, маркетинга и разработки.  
**Контекст запуска:** рекламная кампания **каникулярных интенсивов** минимум на **5 площадках**; горизонт — **последняя неделя мая и всё лето** (актуализировать год в материалах кампании).

## Главная цель

Дать родителю **одно доверенное место**, где он:

1. Понимает **что за смена** (квест), **чему научится ребёнок**, **какие условия и безопасность**.  
2. Видит **свою школу / удобную площадку** в первую очередь (школьный **скоуп**), но при необходимости выходит в **полный каталог** BrainMaster.  
3. Переходит к **записи** по понятной цепочке (часто: выбор площадки и смены → **mos.ru** по текущей модели).

Параллельно команде BrainMaster нужны **глобальность бренда** и **централизованное управление** контентом и **заявками/лидами**, без разрозненных копий текстов по школам.

## Цели по стейкхолдерам

### Родитель (B2C)

- Снизить **трение до записи**: меньше вопросов в чатах школы «а что входит?».  
- Снизить **сюрприз по цене**: прозрачность «ядро BM + пакет площадки», диапазон или цена после выбора базы (см. продуктовые решения в репозитории/плане).  
- Дать **социальное доказательство** там, где оно есть (программы с историей, цифры выпускников — после выверки).

### Школа (B2B2C)

- Короткая ссылка в **скоупе школы**: родитель видит **только релевантные смены этой школы**, без шума по всему городу, с кнопкой «весь каталог».  
- Тексты на сайте **не противоречат** документу «BrainMaster для школ» (Inbox, `.md` / `.pdf`).

### BrainMaster (внутренние)

- **Единый источник правды** по квестам, площадкам, датам смен, ценам (обновляется в одном месте → сайт, скоупы, реклама).  
- **Учёт заявок**: кто нажал, с какой площадки/UTM, статус (см. [Управление-заявками-и-источник-данных.md](Управление-заявками-и-источник-данных.md)).  
- Возможность масштабировать **свои базы** без перелома IA.

## Не цели первой версии (чтобы не расползся скоуп)

- Полноценная **игровая метапрогрессия** (ранги, ИИ-карточки) — дорожная карта, не блокер запуска.  
- Замена **mos.ru** без отдельного продуктового и юридического решения.

## Метрики успеха (предложение — уточнить с маркетингом)

- Доля переходов **скоуп школы → карточка квеста → клик записи**.  
- Доля завершённых переходов на **mos.ru** (или эквивалент целевого действия).  
- Количество **обращений с уточнённой площадкой** и снижение дублирующих вопросов в поддержку.  
- Консистентность: **ноль** публичных противоречий цены/дат между сайтом и объявлением школы.
